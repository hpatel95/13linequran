# Stitch / AI UI Design Prompt: 13-Line Quran App (Palette-Exploratory)

Use the prompt below in **Stitch** (or v0 / Lovable / Figma AI). All hardcoded color palettes have been removed so the AI can generate distinct, creative aesthetic directions for you to choose from.

```markdown
Create a premium, sacred, and distraction-free iOS mobile interface for an iPhone 16 Pro app called "13 Line Quran" (a traditional South Asian / Indo-Pak 13-line Mushaf reader). 

The visual design must feel timeless, peaceful, and respectful—inspired by Apple's highest editorial design standards (like Apple Books and Apple Fitness) fused with subtle, refined Islamic geometric artistry.

Explore a creative, harmonious, and elegant color palette of your choice suitable for a spiritual reading app (for example: warm antique parchment, soft desert sand with muted gold, deep calming obsidian, or tranquil monochrome). Choose contrasting, highly legible tones for ink, paper, accents, and selection highlights.

### Target Device & System Shell
- Device: iPhone 16 Pro (393 × 852 pt viewport).
- Include native iOS status bar (time 9:41, Wi-Fi, battery) and home indicator bar at bottom.
- Use native iOS frosted glass / translucent material blurs for floating chrome.

### Core Screen to Generate: The 13-Line Mushaf Reader & Ayah Selection

Show an interactive iPhone screen displaying Surah Al-Mulk (Chapter 67) on a traditional 13-line page layout with an active verse selected and an elegant bottom sheet pulled up:

#### 1. Top Minimal Navigation Bar (Floating / Translucent)
- Left: Subtle back/index icon with label "Surahs".
- Center: Sacred header showing:
  - Arabic title in elegant Naskh/Thuluth: "سُورَةُ المُلْكِ"
  - English subtitle: "Surah Al-Mulk • Juz 29"
- Right: Page indicator badge pill: "Page 741" and a clean bookmark ribbon icon (inactive outline).

#### 2. Main Center Viewport: The 13-Line Mushaf Canvas
- A beautifully framed, border-contained 13-line lithograph page (justified text with traditional decorative page corner ornaments).
- Top line of the page features a vector decorative Islamic floral cartouche announcing the Surah name.
- Exactly 13 evenly spaced horizontal lines of rich Arabic Indo-Pak Naskh calligraphy.
- Verse 1 is SELECTED: A smooth, translucent highlight tint covers the exact bounds of the first verse ("تَبَارَكَ الَّذِي بِيَدِهِ الْمُلْكُ وَهُوَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ ﴿١﴾"), highlighting both the calligraphy and the circular ayah end-marker rosette.

#### 3. Floating Mini Audio Bar (Docked above bottom sheet / home bar)
- A sleek, floating frosted glass capsule (pill) with subtle shadow:
  - Left: Circular play/pause button with icon
  - Center: Reciter name "Mishary Rashid Alafasy" with an audio wave visualizer or subtle progress track
  - Right: Verse counter "1 / 30" and audio speed pill "1.0x"

#### 4. Bottom Translation & Action Sheet (Half-Expanded Modal)
- A native iOS rounded bottom sheet (cornerRadius: 24px, subtle card elevation, drag indicator pill at top):
  - Header: "Surah Al-Mulk • Verse 1" with a small audio playback icon.
  - Arabic Text Snippet: "تَبَارَكَ الَّذِي بِيَدِهِ الْمُلْكُ وَهُوَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ" (Right-to-Left, prominent size).
  - English Translation (Pickthall): "Blessed is He in Whose hand is the Kingdom, and He is Able to do all things." (Font: elegant editorial serif, comfortable reading size).
  - Action Row (4 clean circular icon buttons with labels below):
    1. "Play Verse" (Play icon)
    2. "Bookmark" (Ribbon icon)
    3. "Copy" (Clipboard icon)
    4. "Share" (Export/share icon)

### Design Directives
- No advertisements, no cluttered banners, no aggressive buttons.
- Sacred, serene, luxury aesthetic with generous whitespace.
- Propose a distinct, beautiful color theme (paper background, ink color, accent metallic/tint tone, and translucent verse highlight).
```
