# Stitch / AI UI Design Prompt: 13-Line Quran App

Use the prompt below in **Stitch** (or v0 / Lovable / Figma AI) to generate the high-fidelity UI mockup for the iPhone app.

---

```markdown
Create a premium, sacred, and distraction-free iOS mobile interface for an iPhone 16 Pro app called "13 Line Quran" (a traditional South Asian / Indo-Pak 13-line Mushaf reader). 

The visual design must feel timeless, peaceful, and respectful—inspired by Apple's highest editorial design standards (like Apple Books and Apple Fitness) fused with subtle, refined Islamic geometric artistry.

### Target Device & System Shell
- Device: iPhone 16 Pro (393 × 852 pt viewport).
- Include native iOS status bar (time 9:41, Wi-Fi, battery) and home indicator bar at bottom.
- Use native iOS frosted glass / ultra-thin material blurs for floating chrome.

### Color Palette & Aesthetics
1. **Background / Canvas**: Antique Parchment Warm Ivory (`#F8F5EE` or `#F4EEDA`) with very subtle, warm paper texture.
2. **Ink / Arabic Calligraphy**: Deep Charcoal Obsidian (`#1A1A1A` - not harsh #000000).
3. **Sacred Gold Accent**: Refined Islamic Antique Gold (`#C5A059`) for surah badges, subtle dividers, and active icons.
4. **Ayah Highlight**: Translucent Warm Gold overlay (`rgba(197, 160, 89, 0.22)`) with rounded corners (4px radius).
5. **Dark Mode Variant (OLED Midnight)**: Deepest Onyx (`#0B0C0E`), soft cream calligraphy (`#E8E6DF`), and muted gold accents (`#D4AF37`).

---

### Core Screen to Generate: The 13-Line Mushaf Reader & Ayah Selection

Show an interactive iPhone screen displaying **Surah Al-Mulk (Chapter 67)** on a traditional 13-line page layout with an active ayah selected and an elegant bottom sheet pulled up:

#### 1. Top Minimal Navigation Bar (Floating / Translucent)
- **Left**: Subtle back/index icon (three horizontal lines or Islamic rosette icon) with label "Surahs".
- **Center**: Sacred header showing:
  - Arabic title in elegant Naskh/Thuluth: "سُورَةُ المُلْكِ"
  - English subtitle: "Surah Al-Mulk • Juz 29"
- **Right**: Page indicator badge pill: "Page 741" (with subtle gold outline) and bookmark ribbon icon (inactive outline).

#### 2. Main Center Viewport: The 13-Line Mushaf Canvas
- A beautifully framed, border-contained 13-line lithograph page (justified text with traditional decorative page corner ornaments).
- Top line of the page features a vector decorative Islamic floral frame/cartouche announcing the Surah name.
- Exactly 13 evenly spaced, horizontal lines of rich Arabic Indo-Pak Naskh calligraphy.
- **Ayah 1 is SELECTED**: A smooth, translucent golden highlight (`rgba(197, 160, 89, 0.22)`) covers the exact bounds of the first verse ("تَبَارَكَ الَّذِي بِيَدِهِ الْمُلْكُ وَهُوَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ ﴿١﴾"), highlighting both the text and the circular ayah end-marker rosette.

#### 3. Floating Mini Audio Bar (Docked above bottom sheet / home bar)
- A sleek, floating frosted glass capsule (pill) with subtle drop shadow:
  - Left: Mini play button (Gold circle with white play/pause icon)
  - Center: Reciter name "Mishary Rashid Alafasy" with a mini wave visualizer or progress bar
  - Right: Ayah counter "1 / 30" and audio speed pill "1.0x"

#### 4. Bottom Translation & Action Sheet (Half-Expanded Modal)
- A native iOS rounded bottom sheet (cornerRadius: 24px, background: `#FFFFFF` with slight warm tint, drag indicator pill at top):
  - **Header**: "Surah Al-Mulk • Verse 1" with a small speaker audio icon.
  - **Arabic Text Snippet**: "تَبَارَكَ الَّذِي بِيَدِهِ الْمُلْكُ وَهُوَ عَلَىٰ كُلِّ شَيْءٍ قَدِيرٌ" (Right-to-Left, font size ~20pt, deep charcoal).
  - **English Translation (Pickthall)**: "Blessed is He in Whose hand is the Kingdom, and He is Able to do all things." (Font: elegant serif like New York / Georgia, 15pt, `#4A4A4A`).
  - **Action Row** (4 clean circular icon buttons with labels below):
    1. "Play Verse" (Gold play icon)
    2. "Bookmark" (Ribbon icon)
    3. "Copy" (Clipboard icon)
    4. "Share" (Square with upward arrow)

---

### Key Requirements
- No advertisements, no cluttered banners, no aggressive buttons.
- Sacred, serene, luxury aesthetic.
- Generous whitespace around the 13-line framed page.
- Clean typography pairing: Traditional Arabic calligraphy for Quranic text, Apple SF Pro for UI navigation, and Apple New York serif for English translation.
```
